# RHYTHM.PLAY

Playable browser rhythm arcade with original synthesized funk music, a polished neon interface, earned Pulse Coins, cosmetic skins, and a leaderboard.

Source repository: https://github.com/taithedev/Rhythm.play

## Run locally

Open index.html in a modern browser. Alternatively run "python -m http.server 8000" in the project directory and open http://localhost:8000.

To deploy, import this GitHub repository into Vercel. Select framework preset Other, project root as root directory, and leave the build command blank. There are no npm packages, build tools, or third-party audio services required.

## Included features

- Full playable four-lane rhythm game with keyboard and mobile controls.
- Original 112 BPM funk synthesizer, bass, keys, drums and lead, synchronized to the note chart.
- Scoring, grades, accuracy, combo, misses, animations, particles, and fullscreen.
- Modern responsive black/purple interface with glow, bloom-like lighting, and accessibility reduced-motion rules.
- Six cosmetic skin palettes and a working shop using earnable Pulse Coins.
- Local player profiles and top-score leaderboard saved in browser localStorage.
- Optional community leaderboard backed by Supabase.
- Original SVG favicon and responsive arcade panels.

## Controls

D, F, J, K: hit notes in each lane.
Space: pause and resume.
On phones or tablets: use the four on-screen buttons.
Press START THE BEAT to authorize audio playback in the browser.

## Worldwide leaderboard setup (optional)

1. Use a Supabase project you control.
2. Run the SQL file supabase/schema.sql in the Supabase SQL Editor.
3. Put the Project URL and PUBLIC anon key in config.js. NEVER put a service_role key, private API key, or database password in a frontend file.
4. Redeploy to Vercel. LEADERBOARD > WORLDWIDE will then read and write shared scores.

The global board is not connected until you configure Supabase. Device scores and the shop work immediately without any backend. Community scores are CLIENT-REPORTED and not verified against gameplay: do not use them to award prizes or anything of real-world value without server-side score validation and rate limiting. Encourage usernames that do not disclose private details.

## Project files

index.html: original self-contained arcade music engine, canvas rhythm gameplay, HUD, and platform hooks.
rhythmplus.js: player profile, coins, shop, skin palette, local scores, and optional remote leaderboard.
rhythmplus.css: bloom, animation, responsive shop and leaderboard presentation.
config.js: optional public Supabase URL and anon key.
supabase/schema.sql: optional community score table, constraints and row-level security.
favicon.svg: vector brand asset.
vercel.json: static deployment configuration.

## Notes

Track: Neon Side Street; duration ~1 minute 43 seconds; tempo 112 BPM. Sound begins only after a user interaction. All music is original and generated by the Web Audio API rather than copied from a recording.

Local progress is per browser. Clearing site storage clears locally saved skins, coins, profile name, and scores. Cloud scores are shared only if Supabase is configured.
