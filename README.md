# Rhythm.play — MONO EDITION

An original browser rhythm game with a black-and-white editorial arcade interface. **Only playable notes, hit particles, and note previews use color.** Focused bloom is rendered directly by Canvas and around the note previews.

## What's live in the source

- Four-lane D/F/J/K rhythm gameplay, touch controls, combo, accuracy and grading.
- Original funk soundtrack generated by the Web Audio API; no copyrighted tracks needed.
- White-on-black UI, clean hairline frames, quiet typography and monochrome buttons.
- Six cosmetic skins that change note-dot palettes, not the entire interface.
- Earnable Pulse Coins, a skin shop and player profile.
- Local scoreboard and a shared Zuzify Supabase worldwide scoreboard.
- Server-managed skin catalog at `public.rhythm_skins`.
- Vercel-ready static site; no build tool or packages.

## Supabase (already configured)

Connected to the **existing Zuzify project** `wfqudstuncdldsvxqveu`. This repository's `config.js` contains only its **public publishable** key and URL. Never add a service-role key or database secret to the web client.

Tables:
- `public.rhythm_scores` — public SELECT / INSERT for optional guest world rankings; RLS enabled. Browsers cannot UPDATE or DELETE.
- `public.rhythm_skins` — public SELECT-only catalog; RLS enabled; 6 seeded cosmetics. Browsers cannot alter catalog prices.

SQL schema and policies are in `supabase/schema.sql`, already deployed in Zuzify. No other Zuzify tables were modified.

**Important:** Global scores are client-reported. The server constrains their shape, but does not independently verify gameplay; shared rankings can be manipulated until an authenticated, server-validated score-submission service exists. Pulse Coins and purchases are local to each browser, not synced between devices; providing secure cloud balances requires accounts and trusted server-side purchases. Do not use client-side scores or coins for real-world rewards.

## Run and deploy

Open `index.html` or run `python -m http.server 8000` and visit http://localhost:8000.

Vercel: import this GitHub repository, framework preset **Other**, root directory **project root**, no build command, and deploy. If an existing Vercel project is already linked to this repo, pushes to `main` can deploy automatically.

`node scripts/check.mjs` runs dependency-free syntax/hook checks. GitHub Actions executes that check for pushes and pull requests.

## Notes

If a browser blocks Web Audio before clicking START, this is expected: the soundtrack starts after user interaction. Browser localStorage saves skins, scores and coins. Site-storage deletion clears that local progress.
